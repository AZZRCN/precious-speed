# 自研算法方向B：基于DCT的实数乘法

## 状态：理论证伪（DCT卷积性质不适用于标准卷积）

## 设计思路

### 核心创新
利用离散余弦变换(DCT)替代DFT实现快速卷积，理论优势：
- 实数运算（数据量减半）
- 利用对称性减少乘法次数
- 避免复数精度问题

### 数学框架
1. 基变换：幂基 → Chebyshev多项式基
2. DCT卷积：Chebyshev域中乘法对应DCT卷积
3. 逆变换：IDCT回到幂基

## 实测结果

### 验证方法
- 方法1：DCT-II直接点积 → IDCT，验证是否等于标准卷积
- 方法2：对称延拓后DCT → 点积 → IDCT，验证是否等于标准卷积
- 20个随机测试用例（na=3-10, nb=3-10, 值域[0,99]）

### 结果
| 方法 | PASS/总 | 结论 |
|------|---------|------|
| 方法1 (DCT直接点积) | 0/20 | DCT对称卷积 ≠ 标准卷积 |
| 方法2 (对称延拓DCT) | 0/20 | 对称延拓后仍无法正确计算标准卷积 |

## 失败原因

### 1. DCT卷积性质不匹配
- DFT卷积定理：DFT(a*b) = DFT(a)·DFT(b)，*为循环卷积 → 适用于大数乘法
- DCT卷积定理：DCT对应"对称卷积"(symmetric convolution) ≠ 标准卷积
- 大数乘法是标准线性卷积，DCT的对称卷积无法直接应用

### 2. 对称延拓无法解决
- 要用DCT做标准卷积，需将输入对称延拓到长度2L
- 但DFT只需长度L的FFT，DCT需长度2L的变换
- DCT计算量 ≥ DFT计算量（DCT可用2L点DFT实现）

### 3. RIRI打包已覆盖实数优势
- CUR的RIRI打包已实现：两个实数序列打包为一个复数序列，1次复DFT
- DCT的"实数运算"优势已被RIRI打包覆盖
- DCT无额外性能优势

## 结论

方向B (DCT乘法) **理论证伪**：
1. DCT的卷积性质（对称卷积）不适用于标准卷积（大数乘法）
2. 对称延拓后长度翻倍，抵消数据量优势
3. DCT计算量 ≥ DFT计算量
4. RIRI打包已覆盖实数序列的高效DFT

**不集成到CUR**，无任何收益。
