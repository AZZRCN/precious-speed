## AMD EPYC 7B13 的基本规格

| 规格项 | 详情 |
|--------|------|
| **代号** | Milan（第三代EPYC） |
| **微架构** | Zen 3 |
| **核心数** | 64核 |
| **线程数** | 128 |
| **基础频率** | 2.2 GHz |
| **L3缓存** | 256 MB |
| **套接字** | SP3 |
| **工艺** | 7 nm |

---

## 指令集支持情况

**AMD EPYC 7B13** 基于 **Zen 3 微架构**，支持的指令集如下：

### 基础指令集
- **AMD64** (x86-64) - 基础64位指令集
- **MMX** 及 MMX+

### SSE 系列
- **SSE1、SSE2、SSE3、SSSE3** - 早期向量指令
- **SSE4a、SSE4.1、SSE4.2** - 扩展SIMD指令

### AVX 系列
- **AVX** - 256位向量扩展
- **AVX2** - 增强的AVX指令
- **FMA3** - 融合乘加指令

### 其他重要扩展
- **ABM** - 高级比特操作
- **BMI1、BMI2** - 位操作指令集
- **AES** - 加密指令
- **SHA** - 安全哈希指令
- **CLMUL** - Carryless乘法
- **RDRAND** - 随机数生成

### 虚拟化和安全
- **AMD-V** - 硬件虚拟化
- **AMD-Vi** - I/O虚拟化

---

## 重要注意事项

**AMD EPYC 7B13 不支持 AVX-512**。AVX-512指令集从 Zen 4 代（EPYC 9004系列/Genoa）才开始支持。如果您的应用需要AVX-512性能优化，Milan代处理器（包括7B13）是不兼容的。
