## H1（最高优先）精度预算"实测化"：预算 2^48 → 2^49~2^50，整体 k+1

**依据（从源码推出的硬事实）**：
- `pick_k` 表（L1111-1118）阈值 u_max(k) = k·2^(42−2k)，反解即预算 **d·4^k ≤ 2^48**（d=64u/k）。
- `g_cycbudget_log2`（L1316）默认 48，注释明说"49/50 仅 mid 例额外红利但越过可证明安全界"——即 48 是**证明界**，不是实测界。
- 绝对墙是卷积系数 round 误差 < 0.5，即 2^52 量级。当前留了 ~2^4 的证明余量（log2(lm)≈21 × 常数 c 吃掉）。
- 严格界形状：|err_j| ≤ c·ε·log2(lm)·‖a‖₂·‖b‖₂。最坏输入 = 全 max digits（all-F hex），L2 范数最大化 ⇒ 误差上界被 all-max 模式逼近。

**(a) 改哪段**：
1. `pick_k` 表整体换算（预算 2^48→2^B 时阈值乘 2^(B−48)）；线性档从 `pick_k(na+nb)` 改为 **`pick_k(2·min(na,nb))`**——系数项数由 min 决定，现在的 na+nb 判据对非平衡乘保守 2×~log2(na/nb) 倍，这是**同一套证明分析内的免费修正**（平衡乘不变，非平衡乘 k 可升）。
2. `CYCB`（环境变量已存在）48 → 49 → 50 逐档试。

**(b) 预期 Ir**：monster u≈2^17.6 limbs 现取 k=14；预算 ×4 ⇒ k=15 ⇒ digit 数 ×14/15，FFT 长度 −6.7%，FFT 核（77%）同步 −6~7%，split/merge digit 数同降。**预计总 Ir −4~−6%**，全 case 普惠。

**(c) 数学不变**（k 变但仍是精确卷积）——bytecmp 应零差异；出差异即该档回退。

**前置闸门（关键，把"经验"变"实测最坏"）——margin-meter**：
- 造 instrumented build：卷积回搬前，对采样系数（每档取 ~64 个，含峰值位置附近 ±16）用 O(d) 点积算 exact 值，量 |FB[j]+0.5 round 前误差|。
- 每档 (k, lm) 测 3 种 adversarial：全 F hex、随机 max-digit、top-heavy。**max err ≤ 0.125（4× margin）才允许升档**。
- 同时可做：用 Percival/Higham 的 sharp 界（twiddle 表各自 ≤0.5ulp 的项单独计）重推一遍证明——若能把 c·log2(lm) 压小，2^49 可能是**可证明**的，就不需要经验 margin。

**风险（明说）**：2^49~50 越过现证明界后，安全性 = "实测最坏模式过 4× margin"，对 LC 固定测试集成立，对假想的更毒输入是概率性防御。margin-meter 数据出来后再决定接受度。

## H2 长商路径（t≥5）改"单次大乘法除法"，替换逐块 Barrett

**依据**：max_r8（na/nb=8）t≈9 ⇒ Barrett 循环 8 轮 × 2 个 n×n 乘积 × 每积 2 次变换 @ lm_b ⇒ 4(t−1)·lm_b·log(lm_b) ≈ 1126n 单位；大乘法方案 4 次变换 @ lm_B≈(t+1)·lm_b/2 ⇒ ≈ 812n 单位，**Barrett 段 FFT −25~−29%**（tier 量化会吃掉一点）。

**(a) 改哪段**：`bz_divide` L1869-1935。t≥5 时改走：
- Q̂ = floor(A·V / B^(64n))，V = 2^(64n)+q2 已有（invertappr 产物），一个 (na+n+1) limbs 的 `mulg`；
- R = A − Q̂·B 第二个大 `mulg`；
- 修正 ≤ 3 轮线性加减（q̂ 偏差 ≤ 2 的标准结论）。
t=2~4（monster/max_r2/max_eq）保持现 Barrett 路径不动。

**(b) 预期 Ir**：max_r8 除法核 −25%±10% ⇒ 该 case 总 **−8~−15%**；其余 case ±0。

**(c) 数学不变**（仍是精确 divrem）——bytecmp 必须零差异。精度预算与逐块相同（min 操作数仍是 n+1 limbs ⇒ 同 k），无新精度风险。

## H3 merge/digit→limb 回搬的 AVX2 批处理重写

**依据**：`cyc_mul_fixed` L1417-1426、`cyc_mul_var` L1508-1517、`merge_b2` L1079-1085 三处同构串行链：每输出 limb ~(64/k+1) 次 {cvttsd2si + 变量 shl + u128 add/adc}。digit 值 < 2^48（预算保证），**每个 digit 只跨 ≤2 个 limb** ⇒ 4-limb 批内可用 `vcvttpd2qq + vpsllvq/vpsrlvq` 拆 hi/lo 双路按 lane 累加（shift ≤16 走 lo 路、>16 走 hi+跨 lane 缝合），批尾一次标量进位缝合。

**(a) 改哪段**：上述三处循环（可先只做 cyc_mul_fixed，invertappr+Barrett 都走它）。
**(b) 预期 Ir**：该循环指令 −40~50%；三处合计估 5~7% 总 Ir ⇒ **总 −2~3%**。与 H1 叠加（k 升则 digit 数本身也降）。
**(c) 位级等价**（同一组整数的和）——bytecmp 零差异，可用 INV_VERIFY 直接 A/B。

## H4 SR(split-radix) drop-in 去掉置换 copy（不确定性最大，先测现版）

**依据**：`sr_dif`（L667，默认关）现实现 = 自然序 DFT + 显式置换 copy，O(n) 额外流量抵消 SR 省的 ~1/8 复乘。**pointwise 本来就是逐点乘，读序可任意重排**——把置换折进 `pointwise_mixed`/`pointwise` 的读序（两谱同序即可），copy 全省。

**(a) 改哪段**：先 `SR=1` 跑 `cgcmp2.sh` 拿现 drop-in 净 Ir；若 ≥ −3% 再做融合版（改 sr_dif 输出约定 + pointwise 读序，`g_sr_rev` 已支持 base-4 反转对接 ditRec）。
**(b) 预期 Ir**：前向 −5~10% ⇒ 总 −2~4%（若成立）。
**(c) 数值路径不同（舍入不同）但 round 后 limb 应一致**——bytecmp 过不了 = 精度余量不足，反哺 H1 margin-meter 结论。

## 对委托词 §5 四问的正面回答

1. **2^52 墙 / 新数值基**：`__float128` 无硬件，Ir 必爆（否）；拆尾数/指数 = double-double 变体（已证伪，否）。**唯一可行路线是 H1：不换基，把预算从证明界推向实测界**。同证明分析内还有 min(na,nb) 判据的免费修正（H1a）。
2. **减少 FFT 次数的除法结构**：Newton 步数无空间（步数=log2(n/INV_BASE) 定死，INV_BASE=24 已 psweep；中积截断已由 cyclic 实现，形状已 ≈2M(n)）。**残值在 H2：换掉 t≥5 的逐块 Barrett 结构**。
3. **绕开串行进位**：H3（SIMD 批处理，不是消灭进位而是 4-lane 并行摊薄）。注意纯"消灭"不存在——NTT 直出已证伪。
4. **分界点重估**：H2 本质就是 t 分界重估；另外建议顺手 psweep `FFT_LEAF_LOG`（现 8，未见于近期 sweep 记录）与 `MULBF_MAX`，各 ±1 档，成本低。
