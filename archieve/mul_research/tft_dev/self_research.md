## 一、当前所有乘法算法的共同局限点

### 1.1 DFT 类算法的局限（FFT/NTT/TFT/MTT/WFTA）

| 局限点 | 详情 | 影响程度 |
|--------|------|----------|
| **蝶形已完全向量化** | addsd/mulsd=0，SIMD 已最优 | 致命：无指令级优化空间 |
| **split-radix 乘法次数已最优** | 理论最少乘法次数 | 致命：无算法级优化空间 |
| **非FFT部分仅占18%** | FFT占82%，非FFT优化天花板18% | 严重：整体收益有限 |
| **padding浪费** | 需padding到2的幂次，浪费最多2x | 中等：TFT尝试解决但递归开销大 |
| **精度限制** | double精度限制BASE=10^4 | 中等：无法增大BASE减少limb数 |
| **小点数优化受限** | WFTA 16/32破坏SIMD流水线 | 中等：W8^1特殊性无法推广 |

### 1.2 分治类算法的局限（Karatsuba/Toom-Cook）

| 局限点 | 详情 | 影响程度 |
|--------|------|----------|
| **中规模才有优势** | Karatsuba拐点约64-128 limbs | 严重：LC中规模用例占比小 |
| **递归开销** | 递归调用和内存分配开销 | 中等：小规模不如basicMul |
| **Toom-Cook分段开销** | 分段、求值、插值的开销 | 中等：常数因子大 |

### 1.3 I/O 主导

| 局限点 | 详情 | 影响程度 |
|--------|------|----------|
| **I/O占比>95%** | fread+oBuffer已最优 | 致命：计算优化天花板低 |
| **输出写回** | oBuffer已最优 | 致命：无法进一步优化 |

### 1.4 硬件限制

| 局限点 | 详情 | 影响程度 |
|--------|------|----------|
| **FMA精度问题** | 单次舍入导致FFT结果变化 | 严重：无法用FMA加速 |
| **NTT指令延迟高** | x86上NTT蝶形6 cycles vs FFT 2-3 cycles | 严重：NTT不可用 |
| **IFMA52不可用** | AVX-512 IFMA52未普及 | 严重：无法用硬件模乘 |

### 1.5 共同局限的根因分析

**核心矛盾**：当前CUR的FFT核心代码与BEST完全相同，占总执行时间82%，已无优化空间。非FFT部分仅18%，即使全部优化也只能获得有限收益。

**突破方向**：必须找到一种**总体思路不同于FFT**的算法，或者**利用FFT无法利用的问题特性**。

## 二、可能的创新角度

### 2.1 数学角度

1. **非DFT变换域**：
   - DCT（离散余弦变换）：实数运算，利用对称性
   - Hadamard变换：只需加减法，无乘法
   - Walsh变换：类似Hadamard，不同基函数

2. **混合基变换**：结合DFT和DCT的优点

3. **多项式基变换**：从幂基到Chebyshev基（SURVEY E2）

4. **数论路径**：非标准NTT模数，利用特殊数论结构

### 2.2 硬件角度

1. **AVX2特殊指令**：
   - VPSHUFB：并行查找表（16×16 → 16字节）
   - VPMULLW：16位乘法（可并行8个）
   - VPERM：向量重排

2. **矩阵乘法SIMD**：将大数乘法转化为分块矩阵乘法

3. **超越传统蝶形的SIMD化**：非Cooley-Tukey结构的并行计算

### 2.3 问题特性角度

1. **LC大数乘法的特殊性**：
   - base=10^4，limb范围[0, 9999]
   - 输入为十进制字符串
   - 输出也是十进制字符串

2. **limb值域小**：可利用查找表或专用编码

3. **输入分布特性**：LC测试点的输入模式（max_max为全9，fft_killer为特定模式）

## 三、新算法方向提案

### 方向 A: 混合自适应算法（中等可行性）

#### 数学框架
根据输入规模N，动态选择最优算法：
```
N < 64:         basicMul (O(n²) 但常数最小)
64 ≤ N < 2048:  Karatsuba (O(n^1.585))
2048 ≤ N < 65536: FFT (O(n log n))
N ≥ 65536:      Six-step FFT (缓存优化)
```

#### 关键创新
- **运行时benchmark决定阈值**：不同于GMP的静态阈值，在程序启动时做微型benchmark测定当前硬件的最优切换点
- **输入形状感知**：不仅根据N，还根据输入分布（如全9、随机、特定模式）选择算法

#### 可行性分析
- **收益**：中等（5-10%），主要来自中规模用例的算法切换
- **风险**：低（算法本身成熟，创新在选择策略）
- **实现成本**：中等（需实现benchmark框架）
- **评估**：LC中规模用例占比小，整体收益有限

#### 与现有算法的区别
GMP已有多级切换，但使用静态阈值。本方向创新在于**运行时自适应**，适应不同硬件环境。

---

### 方向 B: 基于 DCT 的实数乘法（创新性高）

#### 数学框架
利用离散余弦变换(DCT)替代DFT实现快速卷积：

1. **基变换**：将输入从幂基转为Chebyshev多项式基
   - x = cos(θ), T_n(x) = cos(nθ)
   - 多项式 P(x) = Σ a_n x^n → P(x) = Σ b_n T_n(x)

2. **DCT卷积**：在Chebyshev域中，乘法对应DCT卷积
   - DCT(P·Q) = DCT(P) ⊙ DCT(Q) （需修正因子）

3. **逆变换**：IDCT回到幂基

#### 理论优势
- **实数运算**：DCT只需实数，DFT需复数 → 数据量减半
- **乘法次数少**：DCT利用对称性，乘法次数约为DFT的2/3
- **精度更好**：实数运算避免复数精度问题

#### 风险分析
- **基变换开销**：幂基↔Chebyshev基的变换需O(n log n)，可能抵消DCT收益
- **卷积性质复杂**：Chebyshev基的卷积不是标准卷积，需额外修正
- **实现复杂度高**：需重新推导整个卷积流程

#### 可行性分析
- **收益**：不确定（需原型验证，理论上有10-20%潜力）
- **风险**：高（基变换开销可能抵消收益）
- **实现成本**：高（全新算法路径）
- **评估**：受SURVEY E2启发，但需解决卷积性质问题

#### 与现有算法的区别
完全不同的变换域（DCT vs DFT），利用实数对称性减少计算量。这不是简单的FFT优化，而是**全新的数学框架**。

---

### 方向 C: SIMD 查找表乘法（利用问题特性）

#### 数学框架
利用LC大数乘法的limb值域小（[0, 9999]）特性：

1. **limb拆分**：将10^4 limb拆为两个10^2"子limb"
   - a = a_hi * 100 + a_lo (a_hi, a_lo ∈ [0, 99])
   - b = b_hi * 100 + b_lo

2. **查找表乘法**：
   - a * b = a_hi*b_hi*10000 + (a_hi*b_lo + a_lo*b_hi)*100 + a_lo*b_lo
   - 4次100×100乘法 → 可用VPSHUFB做并行查找表

3. **SIMD并行**：
   - VPSHUFB: 16×16 → 16字节查找表（一次查16个值）
   - 将100×100表拆为多个16×16子表
   - 8个limb同时处理（AVX2的256位宽度）

#### 理论优势
- **无精度问题**：整数运算，无浮点误差
- **无padding**：不需要padding到2的幂次
- **SIMD友好**：VPSHUFB是单周期指令

#### 风险分析
- **复杂度O(n²)**：本质是基础乘法的SIMD化，不是O(n log n)
- **仅小规模有优势**：大规模仍需FFT
- **查找表大小**：100×100=10^4项，每项2字节=20KB，L1缓存友好

#### 可行性分析
- **收益**：小规模（N<256）可能快2-4倍，大规模无优势
- **风险**：低（算法本身简单，创新在SIMD化）
- **实现成本**：中等（需精心设计SIMD布局）
- **评估**：可作为FFT的补充，用于小规模路径

#### 与现有算法的区别
不是新算法（本质是基础乘法），但**利用问题特性+SIMD指令**的组合是新的。传统basicMul用O(n²)标量乘法，本方向用VPSHUFB做并行查找表。

---

### 方向 D: 分块 SIMD 矩阵乘法（非 FFT 路径）

#### 数学框架
将大数乘法转化为分块矩阵乘法：

1. **分块**：将N个limb分为√N × √N的矩阵
   - A = [a_{i,j}] (√N × √N)
   - B = [b_{i,j}] (√N × √N)

2. **矩阵乘法**：C = A × B
   - 利用AVX2的FMA指令做4×4分块矩阵乘法
   - 每个元素是limb乘积的累加

3. **重构**：从矩阵乘积恢复大数乘法结果

#### 理论优势
- **无精度问题**：整数运算
- **SIMD效率高**：矩阵乘法的SIMD利用率接近100%
- **缓存友好**：分块后工作集在L1/L2缓存内

#### 风险分析
- **复杂度O(n^1.5)**：介于O(n²)和O(n log n)之间
- **不是真正的卷积**：矩阵乘法≠多项式乘法，需额外处理进位
- **大规模仍需FFT**：O(n^1.5)比O(n log n)慢

#### 可行性分析
- **收益**：中规模（256 < N < 4096）可能有优势
- **风险**：高（矩阵乘法≠多项式乘法，需解决进位问题）
- **实现成本**：高（需设计全新的分块和重构方案）
- **评估**：最不确定的方向，但最具创新性

#### 与现有算法的区别
完全不同于FFT和分治算法，将大数乘法视为**矩阵运算**而非多项式运算。如果成功，将是一种全新的乘法范式。

## 四、优先级排序与建议

| 方向 | 创新性 | 可行性 | 预期收益 | 风险 | 优先级 |
|------|--------|--------|----------|------|--------|
| A: 混合自适应 | 低 | 高 | 5-10% | 低 | P1（稳妥） |
| B: DCT乘法 | 高 | 中 | 10-20%(理论) | 高 | P0（高回报） |
| C: SIMD查找表 | 中 | 高 | 小规模2-4x | 低 | P1（补充） |
| D: 矩阵乘法 | 最高 | 低 | 不确定 | 最高 | P2（探索） |

### 建议执行顺序
1. **方向 B (DCT乘法)**: 创新性高，理论收益大，符合"自研新算法"目标
2. **方向 A (混合自适应)**: 稳妥收益，实现成本低
3. **方向 C (SIMD查找表)**: 可作为小规模路径的补充
4. **方向 D (矩阵乘法)**: 高风险探索，时间允许时尝试

### 与现有算法的根本区别
- **FFT/NTT/TFT/MTT/WFTA**: 都基于DFT（复数域），受限于蝶形向量化已最优
- **Karatsuba/Toom-Cook**: 分治算法，受限于中规模用例少
- **方向B (DCT)**: 实数域变换，完全不同的数学框架
- **方向C (查找表)**: 利用问题特性，非变换域算法
- **方向D (矩阵)**: 矩阵范式，非多项式范式

## 五、结论

当前所有已知乘法算法的共同局限在于：
1. **DFT类**：蝶形已完全向量化，无指令级优化空间
2. **分治类**：中规模用例少，整体收益有限
3. **I/O主导**：计算优化天花板低

突破方向在于：
1. **全新数学框架**（DCT/矩阵）而非DFT优化
2. **利用问题特性**（limb值域小）而非通用算法
3. **运行时自适应**而非静态阈值

建议优先尝试**方向B (DCT乘法)**，这是最有潜力实现算法层面突破的方向。若DCT卷积性质问题可解决，将是一种全新的乘法算法。
