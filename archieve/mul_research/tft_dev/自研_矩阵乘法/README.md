# 自研算法方向D：分块SIMD矩阵乘法

## 状态：理论证伪（矩阵范式无法优于FFT）

## 设计思路

### 核心创新
将大数乘法转化为分块矩阵乘法，利用AVX2 FMA做4×4分块矩阵乘法。

### 数学框架
1. 分块：将N个limb分为√N × √N的矩阵
2. 矩阵乘法：C = A × B，利用AVX2 FMA
3. 重构：从矩阵乘积恢复大数乘法结果

## 失败原因

### 1. 大数乘法 ≠ 标准矩阵乘法
- 大数乘法 = 多项式乘法 = 卷积
- 卷积可表示为 Toeplitz矩阵乘向量：c = T(a) * b
- 标准矩阵乘法 C = A × B 是三矩阵运算，大数乘法只有两个输入
- 无法将大数乘法直接映射为标准矩阵乘法

### 2. Toeplitz矩阵乘向量 = O(n²)
- Toeplitz矩阵乘向量复杂度 O(n²)，与直接卷积相同
- 实测比直接卷积慢 2-10 倍（额外索引计算开销）

### 3. 分块无法降低复杂度
- 分块矩阵乘法复杂度仍为 O(n²)
- 实测比直接卷积慢 6-26 倍（分块开销 + 缓存未命中）
- 即使SIMD FMA化，O(n²) 仍比 FFT 的 O(n log n) 慢

### 4. 矩阵乘法复杂度 > FFT
- 标准矩阵乘法复杂度 O(n^ω)（ω ≈ 2.37）
- 即使将n位数映射为√n × √n矩阵，复杂度 O(n^(ω/2)) ≈ O(n^1.19)
- 这仍比 FFT 的 O(n log n) 慢

## 结论

方向D (矩阵乘法) **理论证伪**：
1. 大数乘法（卷积）≠ 标准矩阵乘法
2. Toeplitz矩阵乘向量 = O(n²)，无优势
3. 分块矩阵乘法无法降低复杂度
4. 即使SIMD化，O(n²) 仍比 FFT 慢
